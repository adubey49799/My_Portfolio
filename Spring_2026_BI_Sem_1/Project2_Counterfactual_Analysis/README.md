\# Project 2 – Counterfactual Analysis



\## Title

Evaluating the Impact of Policy Changes on Economic Outcomes



\## Objective

Use counterfactual analysis (Synthetic Control Method) to evaluate

the impact of a hypothetical COVID-era policy change on California’s

unemployment rate using recent data (2018–2023).



\## Data Source

\- Federal Reserve Economic Data (FRED)

\- State unemployment rate series (e.g., CAUR)



\## Methodology

\- Synthetic Control Method (SCM)

\- Placebo / permutation inference



\## Folder Structure

\- data/: datasets

\- notebook/: Jupyter notebooks

\- src/: Python scripts

\- outputs/: generated results

\- report/: final report
