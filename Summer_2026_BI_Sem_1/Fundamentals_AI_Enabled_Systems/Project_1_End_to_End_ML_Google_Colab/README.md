# Project 1: End-to-End Machine Learning Project in Google Colab

## Course
Fundamentals of AI Enabled Systems

## Term
Summer 2026 BI Semester 1

## Objective
The objective of this project is to run an end-to-end machine learning workflow using Google Colab and the Chapter 2 notebook from the Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow GitHub repository.

## Project Summary
This project uses the California housing dataset to understand the full machine learning workflow, including data loading, exploratory data analysis, data preprocessing, model training, and model evaluation.

- Python
- Scikit-Learn

- NumPy
- Matplotlib
